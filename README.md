# 115年新北TP複訓｜止血帶降位/轉換與鏟式擔架

技術操作站教學網頁（GitHub Pages）。兩個分頁：

- **學員**：課程摘要（PDF 下載）＋ 2 支 YouTube 示範影片
- **指導員**：教學教案（PDF 下載）＋ 實證引言

## 待填內容（定稿後）

1. 把 Word 轉成 PDF，放到 `files/`：
   - `課程摘要_學員版.pdf`
   - `指導員教案.pdf`（來源：止血帶轉換降位與鏟式擔架_技術操作站教案.docx）
   - `鏟式擔架使用_實證引言.pdf`
2. 在 `index.html` 把 `VIDEO_ID_1`、`VIDEO_ID_2` 換成兩支 YouTube 影片 ID。

## 發佈到 GitHub Pages

1. 建一個 repo，把本資料夾內容（`index.html`、`files/`）push 上去。
2. repo → Settings → Pages → Source 選 `main` 分支、根目錄 `/`。
3. 幾分鐘後即可用 `https://<帳號>.github.io/<repo名>/` 開啟。
4. 在現場貼上該網址的 QR code 給學員掃。

> 注意：GitHub Pages 為公開頁面，指導員教案（含解答/計分）會公開可見。若不希望外流，改放精簡版或將該頁內容移除。
